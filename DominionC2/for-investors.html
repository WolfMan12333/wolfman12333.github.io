Problem

Tactical Android devices (ATAK, COMSEC, battlefield apps) are increasingly targeted by advanced adversaries, yet there is a critical lack of realistic, resilient C2 threat emulation tools to test their security in controlled environments – from military cyber ranges to corporate BYOD audits.

Solution – DominionC2

DominionC2 is a dual‑use, multi‑agent Command & Control (C2) framework that emulates real‑world threats against Android endpoints. It enables operators to simultaneously manage multiple agents, retrieve sensitive data (GPS, contacts, SMS, call logs, clipboard), execute shell commands, record audio/video/screen, and export structured reports – even under degraded network conditions.

Key Differentiators (What Makes Us Unique?)

  • ✅ Resilient file transfer – Three‑step file size stabilization + exponential backoff (RFC 7230 compliant).
  • ✅ Multi‑agent by design – Dynamic device list, auto‑refresh, sessionStorage persistence.
  • ✅ Legal & transparent – Physical agent installation, explicit user permission prompts – not a covert spyware.
  • ✅ Modular architecture – Easy to extend with new commands (e.g., GET_BATTERY, Messenger extraction).
  • ✅ Instant reporting – One‑click export to CSV, PDF, XLSX.

Target Markets & Dual‑Use Applications

  • Military / NATO: Cyber range training, COMSEC auditing, ATAK resilience testing, adversary emulation.
  • Commercial: Insider threat detection, mobile DLP validation, penetration testing of BYOD environments (banking, critical infrastructure).
  • Red Teams & Pentesters: Authorised Android security assessments with real‑time C2 capabilities.

Current Status (TRL 4)

Fully functional prototype demonstrated on multiple AVD emulators and physical devices. Core features (contacts, SMS, call logs, clipboard, location, screen/audio/video recording, shell execution, report export) are validated in a laboratory environment.

Next milestone (TRL 5‑6): Validation in a military cyber range / operational environment – planned with DIANA Phase 2 or equivalent funding.
