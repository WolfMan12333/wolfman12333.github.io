Overview

DominionC2 is an advanced mobile surveillance and control framework designed for professional red team operations, lawful intelligence gathering, and advanced penetration testing. The platform enables secure, real-time command & control over Android devices through a fully featured web-based dashboard.

Core Features – Current PRO Edition

  • ✅ GET_CONTACT – Retrieve full contact lists from the target device
  • ✅ GET_SMS – Access inbound and outbound text messages
  • ✅ GET_CALL_LOGS – Retrieve detailed call history
  • ✅ GET_Clipboard – View clipboard contents
  • ✅ GET_Location – Obtain real-time GPS location
  • ✅ Download All Photos – Exfiltrate all stored photos
  • ✅ View Screen Recording – Download and view recorded screen sessions
  • ✅ START/STOP Audio Recording – Control microphone recording remotely
  • ✅ START/STOP Front-Camera Recording – Capture from the front camera
  • ✅ START/STOP Back-Camera Recording – Capture from the rear camera
  • ✅ Upload File to Device – Transfer files to the target device
  • ✅ Execute Shell – Run shell commands remotely
  • ✅ Export CSV/PDF/XLSX – Generate reports from collected data
  • ✅ Toggle Dark/Light Mode – Switch UI themes dynamically
  • ✅ Public IP Configuration – Auto-set server IP for APK builds
  • ✅ Manage Devices – Assign and manage device aliases for quick selection
