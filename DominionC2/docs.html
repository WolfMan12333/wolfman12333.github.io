Overview

DominionC2 is an advanced mobile command-and-control platform developed for red team operators, stealth monitoring, and post-exploitation on Android devices.

Installation


git clone https://github.com/WolfMan12333/DominionC2.git
cd DominionC2
python3 -m venv dominionenv
source dominionenv/bin/activate
pip install -r requirements.txt
python app.py

Features

  • 📱 Screen recording (Android)
  • 📷 Dual camera capture
  • 📤 File upload & exfiltration
  • 🕵️‍♂️ Command-based C2 control
  • 🔒 Persistence & stealth

Web Panel Access

Open http://localhost:4444 in your browser to access the control panel interface.
