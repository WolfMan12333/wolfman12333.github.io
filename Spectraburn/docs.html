SpectraBurn – Documentation

SpectraBurn is an advanced Web Exploitation & Static Code Review Suite. This documentation helps you install, configure, and fully utilize its features.

Installation & Setup

  • Standalone: Available as .exe, .AppImage, .sh.
  • Docker: Pull image from Docker Hub.
  • Requirements: 2 GB RAM, Python 3.10+, Git.
  • Initial setup: configure config.json with API keys and paths.

Core Features

  • Payload Encoder – Encode SQLi/XSS payloads with obfuscation methods.
  • Request Injector – Replay and fuzz HTTP requests.
  • AST Code Analyzer – Analyze source code via Abstract Syntax Trees.
  • Source Obfuscator – Minify or obfuscate target JS/PHP/Python.
  • Static Scanner – Signature-based static analysis of repo files.
  • Reporting – Export results to PDF, CSV, JSON.

AI Mode

  • Requires OpenAI key or compatible local model.
  • Activate via config or UI toggle.
  • Returns severity scores and explanation for each vulnerability.

Integrations

  • Burp Suite extension available (SpectraBurnBridge).
  • CLI Mode for headless batch scans.
  • Project import/export in JSON format.

Security & Ethics

  • All data is encrypted at rest (AES-256).
  • Local scan results never sent online by default.
  • Tool for authorized security testing only.

FAQ

  • Q: My payloads aren’t working. A: Check encoding settings.
  • Q: Why is AST analysis slow? A: Try excluding large folders.
  • Q: Export not generating files? A: Verify write permissions.
